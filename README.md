# Pharmacy Stock Manager

# Application developped in SwiftUI for officine to help them manage products stock, batches, expiration dates.

## Features 

### Dashbooard 
- Inventory overview (products and batches)
- Stock value 
- Low stock alerts 
_ Expiring batches 


### Products 
- Product catalog
- Product details 
- Search and filters 

### Movements 
- Entries and exists for batches
